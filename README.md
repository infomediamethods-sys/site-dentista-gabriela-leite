# Clínica Gabriela Leite — Site (Aurea)

Site institucional single-file (HTML/CSS/JS autocontido, sem dependências externas) da Clínica Gabriela Leite, Florianópolis.

## Como publicar no GitHub Pages
1. Crie um repositório novo no GitHub (pode ser público ou privado — só repositórios públicos têm Pages grátis).
2. Suba o `index.html` desta pasta pra raiz do repositório.
3. Em Settings → Pages, escolha a branch (geralmente `main`) e a pasta `/ (root)`.
4. O GitHub gera uma URL tipo `https://<usuario>.github.io/<repositorio>/` em alguns minutos.

## Arquivo
- `index.html` — o site completo (imagens embutidas como base64, sem pasta de assets separada).
