# Dra. Deyseane Mendes - Site

Site institucional em HTML/CSS/JS, sem etapa de build, da Dra. Deyseane Mendes, dentista no Carrão, São Paulo.

## Como publicar no GitHub Pages
1. Crie um repositório novo no GitHub (pode ser público ou privado; só repositórios públicos têm Pages grátis).
2. Suba o `index.html` e a pasta `assets/` desta pasta para a raiz do repositório.
3. Em Settings → Pages, escolha a branch (geralmente `main`) e a pasta `/ (root)`.
4. O GitHub gera uma URL tipo `https://<usuario>.github.io/<repositorio>/` em alguns minutos.

## Arquivo
- `index.html` - página principal do site.
- `assets/` - imagens usadas no hero e na seção da profissional.
